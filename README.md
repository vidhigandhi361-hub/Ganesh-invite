# Ganesh Chaturthi Invitation

Ready-to-deploy, mobile-friendly single-page invitation for:
**Manav Mehta, Nipa Mehta & Stuti Mehta**

## Deploy on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, `app.js` and the `assets` folder.
3. Open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`.
5. Save and open the generated GitHub Pages URL.

The Google Maps button is already configured.

## Make a video
Open the published page on your phone, start screen recording, scroll slowly through the invitation, then trim the recording in Photos/CapCut. Use 9:16 for WhatsApp Status/Instagram Reels.
